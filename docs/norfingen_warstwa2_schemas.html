SalaryTransaction + Payslip

POST /v2/salaryV2/transaction  ·  POST /v2/salaryV2/payslip

Miesięczna lista płac. Jeden SalaryTransaction na miesiąc, jeden Payslip na pracownika. Generator tworzy Vouchery jawnie — dwa osobne: lista płac + AGA.

Model norweskiego payrollu
Brutto (lønn)
  ├─ Skattetrekk (~33%)  →  2740  →  przelew → 1940 (skattetrekkskonto)
  └─ Netto (wypłata)  →  2710  →  przelew → 1910 (driftskonto)

Osobno: AGA pracodawcy (14,1% od brutto)
  DR 5400 → CR 2700 → przelew → 1910

SalarySpecification — kody lønnsart
KodNazwaKwotaMiesiące
100 Fast lønn roczna_stawka / 12 1–12
920 Skattetrekk ujemne, brutto × 33% 1–5 7–12 nie w czerwcu
260 Feriepenger brutto_rok_poprz. × 12% tylko czerwiec
Logika obliczeń per pracownik
Styczeń – Maj, Lipiec – Grudzień (11 miesięcy)
brutto_miesiecznie  =  roczna_stawka / 12
skattetrekk      =  round(brutto × 0.33)
netto            =  brutto − skattetrekk
aga              =  round(brutto × 0.141)  ← koszt pracodawcy, nie odliczany od wypłaty
Czerwiec — feriepenger (patrz sekcja niżej)
feriepenger  =  brutto_rok_poprz. × 0.12
skattetrekk  =  0   ← feriepenger zwolnione z potrącenia
netto        =  feriepenger
aga          =  round(feriepenger × 0.141)

Voucher Patterns — W2

Każdy typ dokumentu źródłowego generuje konkretny pattern Voucherów i Postingów. Referencyjna mapa dla implementacji Warstwy 3.

Order z invoiceDate — automatyczny (voucherType: INVOICE)
DR 1500 Kundefordringer     kwota incl. VAT
CR 3000 / 3100 Przychód      kwota excl. VAT
vatAmount = kwota VAT jako pole Postingu, nie osobny posting
vatCode: 3 (25%)
SupplierInvoice — koszt operacyjny (voucherType: INCOMING_INVOICE)
DR 6xxx / 7xxx Koszt   kwota excl. VAT  · vatCode: 1 (25%)
CR 2400 Leverandørgjeld     kwota excl. VAT
SupplierInvoice L05 ≥ 30 000 NOK — kapitalizacja (voucherType: INCOMING_INVOICE)
DR 1200 Maskiner og anlegg   kwota excl. VAT  · vatCode: 1 (25%)
CR 2400 Leverandørgjeld       kwota excl. VAT
SalaryTransaction — lista płac (voucherType: SALARY)
DR 5000 Lønn, fast            łączne brutto 16 pracowników
CR 2710 Skyldig lønn          łączne netto
CR 2740 Skyldig skattetrekk   łączne potrącenie
SalaryTransaction — AGA (voucherType: SALARY)
DR 5400 Arbeidsgiveravgift   łączne AGA (14,1% brutto)
CR 2700 Skyldig AGA           łączne AGA
Czerwiec — Feriepenger (voucherType: SALARY)
DR 5000 Feriepenger           brutto_rok_poprz. × 12%
CR 2710 Skyldig lønn          = feriepenger (brak skattetrekk)

DR 5400 AGA feriepenger       feriepenger × 14,1%
CR 2700 Skyldig AGA           AGA od feriepenger
Płatność bankowa — do dostawcy (voucherType: BANK) [opcjonalne W4]
DR 2400 Leverandørgjeld      kwota faktury
CR 1910 Bankinnskudd         kwota faktury
Wypłata netto + przelew skattetrekk (voucherType: BANK) [opcjonalne W4]
DR 2710 Skyldig lønn          łączne netto
CR 1910 Bankinnskudd, driftskonto

DR 2740 Skyldig skattetrekk   łączny skattetrekk
CR 1940 Bankinnskudd, skattetrekkskonto
Priorytet implementacji: Vouchery sprzedaży (auto), SupplierInvoice, SalaryTransaction + AGA + Feriepenger — obowiązkowe dla kompletnego P&L. Vouchery bankowe (płatności) — opcjonalne, zamykają zobowiązania ale nie wpływają na wynik.
