NorFinGenSynthetic financial data platform

A live, continuously-growing dataset of realistic financial data for a fictional Norwegian IT company — free to explore, analyze, or build with. No installation required to look around.

Think of it as a real company's books — orders, invoices, payroll, cash flow — except the company doesn't exist and nobody's data is at risk. Updated automatically every day.

3. Get an API key

An API key is like a personal password that lets a program (not a person) ask this service for data automatically — an API is simply a way for programs to exchange data with each other. You'll want a key if you're writing code, a script, or integrating this into another tool. Just want to look at numbers? Use "Download the data" or "View the analytics report" above instead — you don't need a key for that.

Save this key now — it won't be shown again. Rate limit: requests/hour. (a safety limit on how many requests you can make, so the service stays fast for everyone)
